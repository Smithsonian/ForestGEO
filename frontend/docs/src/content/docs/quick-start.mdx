## 1 · Set up site → plot → census

<ConceptCard
  title="The selection hierarchy"

### Pick (or check) your site

After login, the dashboard shows every site you've been granted access to. Click a site's card to select it, or use the **sidebar dropdown** — both do the same thing. Plots and censuses work the same way.

<Screenshot src={dashboardSites} alt="Sites overview cards on the dashboard" caption="Sites overview — each card shows schema name, entry mode, and subquadrat size." />

<Screenshot src={siteDropdown} alt="Site dropdown in the sidebar" width={420} caption="Selecting a site unlocks the plot view." />

:::note
Don't see your site? An administrator needs to assign it to you. Submit a help ticket from the **?** button in the lower right.
:::

### Pick or create a plot

The plots view splits plots **with quadrats** from those **without**. Click the pencil icon on a card to edit name, coordinates, dimensions, and default units.

<Screenshot src={plotsOverview} alt="Plot overview separated by quadrats" caption="Plots are alphabetised within each group." />

<Screenshot src={plotEdit} alt="Plot editing modal" width={560} caption="The plot edit modal — coordinates and units feed validations, so change them only when needed." />

### Add a census

With a site and plot selected, the dashboard shows the censuses for that plot. Click the dashed
**Start New Census** card to create one. The sidebar's Census dropdown only lets you switch
between censuses that already exist — it has no create action.

A short form asks for a **description**, a **start date**, and optionally an **end date**. A
census is just a date range you'll attach measurements to next.

<Screenshot src={addCensus} alt="Census dropdown in the sidebar" width={420} caption="The Census dropdown switches between existing censuses. To create one, use the dashed card on the dashboard." />

<Screenshot src={censusOverview} alt="Census overview with numbered actions" caption="① Delete the most recent census · ② Start a new census from the overview." />

:::caution
You can't create a new census while the current one has **zero** measurements. Import (next section) before rolling forward.
:::

## 2 · Import a census from CSV

<ProcessFlow
  title="Upload pipeline"
  direction="horizontal"
  steps={[
    { label: 'Drop file', description: 'CSV / TSV / TXT' },
    { label: 'Review preview', description: 'check parsed rows' },
    { label: 'Ingest', description: 'stored proc' },
    { label: 'Validate', description: 'site rules' },
    { label: 'Complete', description: 'failures triaged' }

/>

There is no Upload page in the sidebar. Uploading always starts from the grid you want to load
data into — open **Census Hub → View Data** and click **Upload** on that grid's toolbar. The
supporting-data grids under **Stem & Plot Details** each carry the same button.

The first screen asks you to choose an upload mode. For a census you are loading for the first
time, choose **Clean Re-Upload**. For corrections to a census that already holds data, choose
**Revisions Upload** — see the caution below.

Then drop a CSV/TSV/TXT file or browse to it.

<Screenshot src={uploadStage} alt="Upload stage 1 — file dropzone" caption="Stage 1 — file selection. Save your file as UTF-8; the delimiter is detected automatically." />

<Screenshot src={uploadHeaders} alt="Header guide accordion expanded" caption="Click 'Show Header Guide' to see required vs. optional columns and example values before you upload." />

:::danger
**Clean Re-Upload deletes the census's existing measurements before inserting yours.** It does
not merge, and it cannot be undone from the interface. If you only mean to correct some rows,
go back and choose **Revisions Upload** instead.
:::

:::caution
**Don't navigate away during upload.** A file may be up to 500 MB, and large files take several minutes.
:::

<Screenshot src={uploadComplete} alt="Upload complete view with summary" caption="Upload complete — successes land in coremeasurements; failures are surfaced for review." />

## 3 · Edit the census

Open **View Data → Measurements** to see what landed. The grid is editable inline.

<Screenshot src={viewData} alt="Measurements grid with rows" caption="The measurements grid — every column is filterable; row state colours indicate validation status." />

<Screenshot src={editToolbar} alt="Edit toolbar numbered" caption="Toolbar: ① headers accordion · ② columns chooser · ③ filter · ④ clear search · ⑤ search field · ⑥ refresh · ⑦ paste · ⑧ upload · ⑨ download · ⑩ show/hide cells · ⑪ more actions." />

### Fix anything that failed

Rows that didn't pass validation are listed under **Census Hub → View Errors**, in the Errors
Explorer. Each row keeps the original values from your CSV alongside the reason it was rejected,
so you can see exactly what the file said.

You have two ways to fix them: edit the fields **in place** in the grid, or upload a CSV of
corrected values as a **revision upload** — the same file format as the original import, scoped
to just the rows you're fixing.

<Screenshot src={failedMods} alt="Failed measurements listing with reasons" caption="Each failed row carries its original CSV codes plus the consolidated failure reason." />
